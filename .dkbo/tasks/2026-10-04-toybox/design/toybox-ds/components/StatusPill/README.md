# StatusPill

一句話的狀態標記，例如 Hero 上方的「目前在做」。不可點。

| 項目 | 規格 |
| --- | --- |
| Padding | `space-2` `space-4`（高約 42px） |
| 文字 | `label` 15/20 700，`ink` |
| 外框／圓角／底 | `border-m` `line`／`radius-pill`／`surface-raised` |
| 狀態點 | `dot` 12px 圓、`border-s` `line`，與文字間距 `space-2` |

**Tone**（只換點的顏色）：`success`（預設，進行中）、`pop`（開發中）、`action`（需要注意）。不做陰影：它是標籤不是按鈕。
