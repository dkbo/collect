# 糖果消消樂全面美化：方向稿 spec

> 雜務 chore-designer-1，2026-09-25。只出方向，不改程式。
> 使用者已定的方向：做成真糖果的樣子（像 Candy Crush 那樣光滑、立體、有高光、有糖紙質感），範圍全改（棋子、特殊糖、背景、棋盤框、HUD、關卡／結算畫面）。

## 1. 現況盤點（改版前的基準）

- **視窗**：`project.godot` 設 960×540、`stretch=canvas_items`、`aspect=expand`、渲染器 `gl_compatibility`、`default_texture_filter=1`（linear）。BoardView 用 `scale = min(vp)/540` 等比縮放，所以全螢幕 1080p 時會放大到 **2×**，手機直式會小於 1×。
- **棋盤**：`CELL=56`，盤面 448×448，以節點原點為中心。外框是 14px 雙層（`#3b2a52`／`#160f24`）。格子是棋盤格 `#1e293b`／`#243349`。清屏色 `#0d1726`。
- **糖果**：`candy_piece.gd` 用 `_draw()` 畫，`RADIUS=22`。6 色各有自己的形狀：0 紅圓、1 黃圓角方、2 綠三角、3 藍菱、4 紫六角、5 橙甜甜圈。特殊糖 `Special` 有 NONE、STRIPED_H、STRIPED_V、WRAPPED、WRAPPED_ARMED、BOMB；炸彈的 `color=-2`。選取時做呼吸縮放（1.14↔0.98，每段 0.35s）。
- **Godot 內文字**：`_show_banner` 會顯示 `Level N`、`Sweet!`／`Tasty!`／`Divine!`（連鎖第 1／2／3 層以上）、`Sweet Crush!`、`No more moves!`，全部是英文，粉字 `#fbcfe8`，外框 `#831843`。
- **HUD 與結算（React：`src/pages/CandyCrush/index.tsx`）**：遊戲框上方有一條 HUD，內容是關卡、分數、目標、星級進度條（刻度 50/75/100%，滿格＝2 倍目標）、步數（≤5 轉紅）。另有 iframe 內的覆蓋層：暫停、結算（勝／敗、3 星、得分、重玩／下一關／從第 1 關）、操作說明，以及右上的浮動鈕（靜音、暫停、全螢幕、說明）。這些資料都從 bridge 的 `STATE`／`LEVEL_END` 來，**改版不需要動 bridge 協定**。

## 3. 推薦：A · Glossy Classic

理由：
1. **最貼使用者要的方向**。飽和硬糖、左上鏡面高光加一顆硬白點、深色內緣造出的立體感，就是 Candy Crush 的招牌語彙；包裝糖的白框玻璃紙加鋸齒扭結，做出了「糖紙」質感。
2. **可讀性最好**。6 色色相分得開，加上「每色一種形狀」（圓、方、軟糖、菱、六角、甜甜圈）保留原本的形狀編碼，對色盲友善。原本的三角改成圓頂軟糖（gumdrop），更像糖。
3. **和站內頁面一致**。站內是 slate-950 深色，iframe 底色 `bg-slate-950`；紫夜空接得上，B 的亮底則會像另一個網站。
4. **實作成本最低**。全部可以烘成靜態 WebP 貼圖，不需要逐顆 shader，也不需要 additive 發光，gl_compatibility 加 Web 都穩。

可以向其他變體借的元素（選配，不影響主方案）：
- 已引爆包裝的脈動外發光，借 C 的做法（只用在已引爆這一顆，不會全盤都亮）。
- B 的巧克力豆點綴可以用在過關結算卡的邊角裝飾。

## 4. A 方案：糖果規格

### 4.1 座標與畫布

- 邏輯格仍是 56×56，**每顆素材畫布 64×64（@1x）**，四邊各留 4px 給落影與包裝扭結。放置時中心對齊格心，程式尺寸不變。
- 交付 **@2x（128×128）作為唯一檔案**。遊戲縮放範圍在 0.7×–2×，一張 128 的貼圖在 1× 時用 0.5 倍縮小繪製，並開 mipmaps。預設的 linear filter 已經是 1，不需再設。這樣不用維護兩套檔案。

### 4.2 圖層順序（下→上，每顆一致）

1. **落影**：外陰影 y+3、blur 4、`#1a0b3c` 53%（@1x 數值，@2x 乘 2，下同）
2. **本體**：徑向漸層，中心 (36%, 30%)，範圍 140%；色標為 亮色 0% → 本色 42% → 暗色 100%
3. **內緣暗邊**：內陰影 y−4、blur 6、暗色 67%。A 不描實線外框，立體感靠這層
4. **頂緣內光**：內陰影 y+2、blur 2、白 40%
5. **高光**：白色橢圓，徑向羽化，0–55% 為 95% 不透明，到 100% 漸變為 0；依形狀旋轉，位置見 4.3
6. **鏡面點**：4×4 純白硬點。有這一點才有「糖」的感覺，不能省

### 4.4 特殊糖

| 種類 | 做法 |
|---|---|
| **條紋·橫 STRIPED_H** | 形狀與該色一般糖相同。本體改用 7 等分硬邊條紋，本色與奶白 `#FFFDF5` 交替，條紋走水平；上面再疊一層陰影（徑向，白 33% → 透明 40% → 黑 40%），讓條紋也有球面感。高光與鏡面點照舊。 |
| **條紋·直 STRIPED_V** | 同上，條紋改成垂直。消除方向與條紋方向一致，玩家一眼就能判斷。 |
| **包裝 WRAPPED** | 玻璃紙本體：38×38、圓角 11、位置 (9,9)，填本色徑向漸層，外框白 2.5px（87%）。左右各一個鋸齒扭結 12×16，位置 (0,20) 與 (44,20)，填本色、描白 1px 67%。中心放 46% 大小的該色形狀（亮色版），當「糖心」，**保留形狀編碼**。內圈 32×32 再描一條白 1px 40% 當玻璃紙反光。高光用方形那組，縮 82%。 |
| **包裝·已引爆 WRAPPED_ARMED** | 玻璃紙改成粉色（`#FFD1E8` / `#FF4FA3` / `#A3125E`），外框也改粉色 `#FF4FA3`，外面加粉色外發光（blur 12、spread 3）。糖心保留原色，所以仍看得出原本是哪一色。動態見 §7。 |
| **彩色炸彈 BOMB** | 巧克力球 50×50，徑向漸層 `#9A6240` → `#5A3019` → `#2A1208`。表面撒 14 條 3×8 的圓角糖粒，依序用 6 色本色、隨機角度，各描白 0.5px。高光與鏡面點用紅球那組。 |
| **選取態** | 保留現有呼吸縮放（1.14↔0.98）。糖果下方加一張暖白光暈 `#FFF4B3`（徑向，50% 處 80% 不透明，外緣 0%），大小 70×70，比格子大 14px。 |

| `board_frame.webp` | 256×256 | 128×128 | 1 | NinePatchRect 九宮格邊距 56px（@2x）。盤面半透明底、白邊、圓角 26、底部落影 |

合計 49 張，每張 128² 約 6–10KB，總量約 **0.4–0.6MB**。

以下**不做成素材**：
- **格子**：用程式畫 53×53、圓角 9 的格，顏色 `#3A2C8C` / `#30237A` 交替（StyleBoxFlat 或 `draw_rect` 都可以）。
- **文字**：Godot 內的 banner 全是英文，只需匯入 Fredoka Bold（.ttf，SIL OFL），配 LabelSettings 做外框與落影。不要把中文字型塞進 Godot 的 .pck，中文只在 React 側用。
- **React HUD 與結算**：用 CSS 或 Tailwind 就做得出來，星星用 SVG（lucide `Star` 加漸層 fill 或 inline SVG），不需要 WebP。

素材可以從 `variant-A.pen` 的特寫表直接匯出。每顆糖的 frame 是 56×56，但落影與扭結超出 frame，匯出前要先把 frame 擴到 64 並置中，或由 assets 角色照 §4 重繪。

## 6. A 方案：HUD、結算、其他畫面

### 6.1 版面：HUD 移進遊戲畫面兩側（建議，需裁決）

16:9 的 iframe 畫面裡，盤面只佔中間 476px，兩側各有約 240px 空著。mockup 把 HUD 放進兩側，把上方那條 HUD 拿掉：
- 左欄 x=24、寬 196（佔 20.4%）：關卡牌 → 目標分數卡 → 步數糖球。
- 右欄 x=740、寬 196：頂部 4 顆圓鈕（靜音、暫停、全螢幕、說明），下面接分數卡（分數、星級進度條、「下一顆星 N」）。
- 做法：React 在 `.rpg-screen` 內用 absolute 疊在 iframe 上，寬度用 % 或 container query 單位，跟著畫面縮放。Godot 與 bridge 都不用改。
- 直式或窄螢幕（寬高比 < 4:3）：退回現有的上方橫條，但換成 A 的配色。
- 如果不採用，就保留上方橫條，只換配色與元件樣式（6.2 的類別照樣適用）。

### 6.3 結算畫面（勝）

- 遮罩：`bg-[#12083a]/80` 加 `backdrop-blur-[6px]`。
- 卡片：420×380，置中偏上。`rounded-[30px] border-4 border-white bg-gradient-to-b from-[#fff8fc] to-[#ffe0ef]`，陰影 `0 16px 40px #0008`。內距上 62、左右 32、下 28，元素間距 14。
- 緞帶標題：寬 460（比卡片寬 40）、高 62，壓在卡片上緣。粉色漸層、白色 3px 邊、落影 `0 5px 0 #8c0f4a`，文字「第 N 關 通關！」用 Noto Sans TC 900、28px、白色。
- 星星：64／84／64，中間那顆高 22px。每顆星依序在 0.25s 內從 0 彈到 1.2 再回 1，間隔 0.2s；未得的星不播動畫。
- 分數：「得分」15px `#a0668a`；數值 Fredoka 52px `#7a1d52`，從 0 滾到最終分數（0.8s）。
- 副標：「目標 X · 再 Y 分拿第 K 顆星」13px。三星時改成「完美通關！」。

## 7. 特效建議（只描述，不實作）

| 時機 | 建議 |
|---|---|
| 消除（現在是縮到 0 再噴 10 顆粒子） | 糖果先在 0.06s 內放大到 1.15（squash），再用 TRANS_BACK 縮到 0（維持 0.2s）。同時在格心播 `fx_flash`：用本色 modulate，scale 0.4→1.3、alpha 1→0、0.18s、`CanvasItemMaterial.blend_mode=ADD`。粒子換成 `fx_sugar` 貼圖並旋轉，數量維持 8–12 顆。 |
| 連鎖升級 | 連鎖第 k 層時，閃光加大 1+0.1k，粒子數加 2k；音高已經會逐層升，視覺跟著放大。 |
| Combo 字 | 依 §6.5 的樣式。動畫：scale 0.3→1.15→1.0（TRANS_BACK 0.25s）、旋轉 −6°→0，停 0.35s，再上升 20px 並淡出（0.25s）。背後加一張放大的 `fx_flash`（alpha 0.5）當爆光。 |
| 條紋糖流光 | 待機時每 2.5s 有一道斜向白光掃過（寬 12px、45°、0.4s）。建議只在特殊糖節點上用 shader，做 UV 位移配形狀遮罩；做不到就用 AnimationPlayer 帶一張 sheen 貼圖，靠 `clip_children` 遮罩。觸發時：`fx_stripe_beam` 沿行或列 0.25s 展開到整盤寬，同時對那一排格子逐格延遲 0.02s 播消除。 |
| 包裝糖 | 待機時兩側扭結 ±6° 擺動（1.2s，loop）。第一段爆炸：`fx_ring` 以 3×3 範圍 scale 0.3→1.6、alpha 1→0、0.3s，加 4px 畫面震動 0.15s。 |
| 已引爆包裝 | 外發光脈動：scale 1.0↔1.08、modulate 亮度 1.0↔1.3，0.6s loop，直到第二段爆炸。 |
