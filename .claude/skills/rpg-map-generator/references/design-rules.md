# 場景設計規範

從現有 4 張地圖（0000 大地圖、0001 花草屋、0002 房屋 1F、0003 房屋 2F）歸納。

## 網格

- 一切對齊 **32px**；地圖尺寸為 32 的倍數；角色佔 **32×48**。
- 貼圖 `l/t` 與 `w/h` 為 32 倍數（碰撞區可例外用 1~8px 薄條）。

## 室內房間模式

1. **地板**：`地板`(b1 64,6528) 或 `地毯`(b2 0,4064) 以 `rx/ry` 鋪滿室內。
2. **上緣牆**：`牆壁`(b2 0,64 32×64) 沿房間上緣，視覺高 64 但**碰撞只佔上半 32**
   （讓角色頭部可與牆面視覺重疊）。
3. **外框遮罩**：`天花板`(b2 32,3424, z=2) 沿室外圍一圈，遮出房間輪廓。
4. **門開口** 寬 ≥ 64px；門口放 `cm/cmm` 傳送碰撞區（高 1~8px 薄條，貼地圖
   邊緣或門檻位置）。
5. **四周邊界**必須有牆碰撞或傳送點，防止走出畫面。

## 碰撞原則（RPG Maker 慣例）

- 家具碰撞框「**比視覺略窄、只擋下半**」：桌子 86×22 擋桌面下緣、雕像 32×3
  只擋底部——讓角色上半身可與物件視覺重疊。
- 對話物件用薄條 `{w:32, h:1, e:N}` 貼物件下緣。
- 傳送區不阻擋，玩家走入即觸發，故要放在開口處而非牆內。

### 樓梯傳送的正確設法

**傳送區必須放在玩家站在樓梯頂部時、往下走就能觸發的位置**。
關鍵計算（speed=4, 角色高 nY=48）：

```
玩家 py 往下走: cy = py + 4；觸發條件: cy + 48 >= portal.y
→ 傳送區 y <= py + 4 + 48 - 1 = py + 51
```

樓梯開口若在視覺 t=160（3 列樓梯 top），玩家站在 py≈168：
→ 傳送區 y 最高可到 168+51 = 219，建議設 `y=222, h=4`（貼近中段）。

**常見錯誤**：傳送區 y 設得比玩家底部還遠（如 y=240 而玩家底部只到 226），
導致觸發不了。**同時要確認傳送區上方沒有橫向阻擋薄條**（純擋路用途的
無名薄條應刪除，不要留著擋住下樓路徑）。

### 大樹碰撞的正確設法

大樹由「樹冠（fg z=2）+ 樹幹（bg）」兩組 tile 組成。
**碰撞只放樹幹底部 4px 薄條**，讓玩家能走進樹冠下方並被遮罩覆蓋：

```
樹幹 bg: t=T_top, h=32 → 視覺 y = T_top ~ T_top+32
碰撞設定: y = T_top+28, h = 4   （只擋最後 4px）
```

AABB 判斷：`cy + 48 >= c.y` → 玩家底部恰好貼住樹幹底時才擋。
若設得太高（如 y = 樹冠底部），玩家離樹還遠就被擋，體感像空氣牆。

**判斷邊界公式**（speed=4）：
玩家 py 最低可走到 `c.y - 48 - 4 + 1 = c.y - 51`；  
即樹幹底 y=1120 → 玩家可走到 y≈1069 才被擋（而非從樹冠區就開始擋）。

## 前景遮罩（z=2）

樹冠、屋簷、家具上緣、室內外框等「角色走到後面會被遮住」的部分拆成
z=2 tile。家具常見拆法：上半 z=2（可遮角色）、下半 bg + 碰撞。

## 出生點 in[]

- 落點必須在可行走區（不與任何碰撞/NPC 相交，含 32×48 全身）。
- 面向場景內側（進門後背對門）。
- 索引與其他地圖的 `cmm` 對應，刪除/重排會破壞既有傳送，**只能追加**。

## NPC

- `pX/pY` 對齊 32 網格；`e` 索引必須有對應 `messages[e]`，否則不顯示。
- 行走型（type:4）設 `aX/aY/aW/aH` 活動範圍，範圍不可與碰撞區重疊。
- NPC 自帶碰撞，不要再疊 isMove。
- **引擎只取 NPC 下半身碰撞**（`y = pY+24, h = 24`）：玩家可走到 NPC 上方
  與其上半身視覺重疊。擺位時確認 NPC 腳部碰撞帶（pY+24 ~ pY+48）的
  下方至少留 24px 可行走空間（含與牆碰撞的距離），否則下方無法通行。

## 雕像/直立裝飾物的擺位

- 碰撞只放視覺底部 3~4px 薄條。
- **不要放在走廊中段**——雕像會把走廊夾成幾 px 的縫隙；
  應靠牆放（嵌在牆面視覺下半），或放在開闊房間的角落。

## 傳送配對檢查

A→B 與 B→A 的 `cm/cmm` 必須互相成對：
```
0000 { cm:1, cmm:0 }  →  0001 的 in[0] 在門內側
0001 { cm:0, cmm:0 }  →  0000 的 in[0] 在房子門口外
```
新地圖一定要有回程傳送，否則玩家進得去出不來。

## 對話風格

現有 NPC 以「哆拉◯」命名（哆拉樹、哆拉花、哆拉貓…），語氣輕鬆、
第一人稱介紹場景或作者；2~4 句為宜。
