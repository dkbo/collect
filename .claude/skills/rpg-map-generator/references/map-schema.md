# 地圖 JSON Schema

一張地圖 = 一個 `src/pages/RpgRoom/data/000N_map.json`。TypeScript 型別定義在
`src/pages/RpgRoom/types.ts`（`MapJsonData`）。

```jsonc
{
  "map": {
    "index": 4,            // 必須等於檔名編號（000N），也是 cm 引用的索引
    "name": "臥室",         // HUD 顯示名稱
    "width": 960,           // 32 的倍數
    "height": 640,          // 32 的倍數
    "in": [                 // 傳送落點清單，索引對應其他地圖碰撞區的 cmm
      { "x": 464, "y": 544 }   // 玩家左上角座標（角色佔 32×48）
    ]
  },
  "styles":   [ /* 貼圖（見下） */ ],
  "isMove":   [ /* 碰撞/事件/傳送區（見下） */ ],
  "npc":      [ /* NPC 定義（見下），可為 [] */ ],
  "messages": [ /* 對話（見下），索引對應 e */ ]
}
```

## styles[] — 貼圖

```jsonc
{
  "n": "地板",   // 名稱（語意標記，建議必填，供日後萃取目錄）
  "l": 64,      // 畫布 X（目的座標）
  "t": 96,      // 畫布 Y
  "w": 32,      // 寬（同時是來源裁切寬）
  "h": 32,      // 高
  "b": 1,       // 圖庫：0=man.png(128×1344) 1=rpg_maker_xp.png(256×12000) 2=rpg_maker_xp2.png(256×7000)
  "x": 64,      // 圖庫來源 X
  "y": 6528,    // 圖庫來源 Y
  "z": 2,       // 選填：2 = 前景遮罩層（蓋在角色上方）；省略 = 背景層
  "rx": 28,     // 選填：沿 X 重複貼 28 次（步距 = w）
  "ry": 16      // 選填：沿 Y 重複貼 16 次（步距 = h）
}
```

- 繪製順序 = 陣列順序（後蓋前），同層內先鋪地板再放家具。
- `rx`/`ry` 是壓縮欄位：`{l:64, t:96, w:32, h:32, rx:28, ry:16}` 等同
  28×16 = 448 筆單格貼圖。大面積地板/牆務必使用。
- 沒被 styles 覆蓋的區域顯示草地底圖（bg.jpg 32×32 無限平鋪）。

## isMove[] — 碰撞 / 事件 / 傳送

```jsonc
{ "n": "牆",   "x": 0,   "y": 0,   "w": 960, "h": 32 }                     // 純碰撞（阻擋）
{ "n": "石碑", "x": 224, "y": 160, "w": 32,  "h": 1, "e": 2 }              // 對話事件：e = messages 索引
{ "n": "門口", "x": 448, "y": 632, "w": 64,  "h": 8, "cm": 0, "cmm": 1 }   // 傳送：到地圖 cm 的 in[cmm]
```

- 玩家 AABB 為 32×48（左上角座標），邊界接觸即判定碰撞。
- 帶 `e` 的區域同時是阻擋區；玩家面向它按互動鍵觸發對話。
  慣例用薄條（h:1~8）貼在物件下緣。
- 帶 `cm`+`cmm` 的區域玩家走入即傳送（不阻擋）。`cm` 是目標地圖
  `map.index`，`cmm` 是目標地圖 `map.in[]` 的索引，兩者都必須 >= 0 且存在。
- 傳送必須成對：A→B 也要在 B 配 B→A。

## npc[] — NPC

```jsonc
{
  "b": 0, "type": 0,            // b: 圖庫（NPC 一律 0）；type: 0=站立 4=行走
  "pX": 480, "pY": 352,         // 位置（對齊 32 網格）
  "aX": 416, "aY": 320,         // 活動範圍（行走型用；範圍內不可有碰撞區）
  "aW": 160, "aH": 128,
  "mX": 0, "mY": 0,
  "x": 0, "y": 0,               // spritesheet 來源（一律 0,0）
  "w": 32, "h": 48,             // 尺寸（一律 32×48）
  "d": 0,                       // 朝向：0=下 1=左 2=右 3=上
  "l": 1, "r": 2, "u": 3, "t": 0, "s": 0, "f": 0,
  "footSpeed": 8,
  "isR": false, "isU": false, "isD": false, "isL": false, "isM": false,
  "e": 1                        // 對話：messages[1]；若無對應 message 則 NPC 不會顯示
}
```

- NPC 自帶碰撞（pX/pY/w/h），不必另開 isMove；玩家面向 NPC 按互動鍵觸發 `messages[e]`。
- **`messages[e]` 不存在的 NPC 不會被繪製**（運行時以此判斷啟用）。

## messages[] — 對話

```jsonc
{
  "name": "哆拉貓",                 // 對話框顯示的名字
  "text": [                        // 逐句顯示，按互動鍵推進，講完自動關閉
    "喵～",
    "請按 [[kbd:ESC]] 開選單",       // markup：按鍵樣式
    "詳見 [[link:https://example.com|官網]]",  // markup：外部連結
    "重點是 [[mark:這個]]"           // markup：紫色重點標記
  ]
}
```

- 索引制：`isMove[].e` 與 `npc[].e` 都指向本陣列索引，**只能往後追加**。
- markup 由 `src/pages/RpgRoom/lib/messageRenderer.tsx` 轉成 ReactNode。
