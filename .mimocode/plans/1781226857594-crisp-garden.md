# 坦克對戰 — 實作計畫

## 背景

`src/babylon/games/tank.ts` 目前不存在。`REGISTRY.tank` 指向 `placeholderScene.ts`（可移動方塊 demo）。需要建立完整的坦克對戰遊戲。

## 遊戲設計

### 核心機制
- **移動**：WASD/方向鍵，車體轉向移動方向，砲塔可獨立旋轉（Q/E 或滑鼠）
- **射擊**：空白鍵發射子彈（沿砲塔方向），冷卻 500ms
- **HP 系統**：每台坦克 3 HP，被子彈命中 -1 HP，歸零 = 毀損
- **障礙物**：不可破壞水泥牆 + 可破壞木箱
- **道具**：HP 恢復、加速、速射
- **勝利條件**：最後存活的玩家獲勝

### 視覺風格（2.5D 等距視角）
- **坦克**：Box 車體 + Cylinder 砲塔 + 細 Cylinder 砲管，玩家顏色（hash from ID）
- **地面**：深色軍事綠 + 網格線
- **水泥牆**：灰色方塊，木箱：棕色方塊
- **子彈**：小型發光球體
- **HP 條**：坦克上方浮動 3 個小方塊（綠=滿/黃=1/紅=低）
- **射擊特效**：發射時短暫閃光
- **爆炸特效**：命中時多個小方塊向外擴散
- **相機**：固定俯視 2.5D（不開放操作）

### 網路模型（Host Authority）
- 所有權同步：各玩家廣播自身位置/車體旋轉/砲塔角度（20Hz）
- Guest 發送 `shootReq` → Host 驗證 → 廣播 `bullet`（含位置/方向/owner）
- Host 管理：子彈生命週期、碰撞偵測、HP 變化、道具掉落、勝負裁決
- 消息類型：`shootReq`, `bullet`, `hit`, `destroyed`, `item`, `pickup`, `restartReq`

### 道具（木箱摧毀後 Host 決定掉落）
- HP 恢復（綠色十字）：+1 HP（上限 5）
- 加速（藍色箭頭）：+25% 移動速度，持續 5 秒
- 速射（橘色子彈）：冷卻減半，持續 5 秒

### HUD
- TextPanel：存活人數、自己的 HP、擊殺數
- Banner：倒數數字、GO!、結算結果
- HP 條：坦克上方 3 個小方塊

## 要修改的檔案

### 1. 新建 `src/babylon/games/tank.ts`（~700 行）

**Class: TankScene implements GameModule**

**狀態結構：**
```ts
interface TankState {
  x: number; z: number;    // 車體位置
  ry: number;              // 車體旋轉角
  turretAngle: number;     // 砲塔角度
}
```

**網路消息：**
- `shootReq` → guest → host: `{ x, z, angle, turretAngle }`
- `bullet` → host → all: `{ id, owner, x, z, vx, vz, speed }`
- `hit` → host → all: `{ bulletId, targetId, hp }`
- `destroyed` → host → all: `{ targetId }`
- `item` → host → all: `{ cx, cy, kind }`
- `pickup` → host → all: `{ ci, who }`
- `restartReq` → guest → host: `{}`

**模擬流程（30Hz fixedTick）：**
1. 移動：WASD → 計算新位置 → 碰撞牆/箱/邊界 → 更新 state
2. 砲塔旋轉：Q/E → 更新 turretAngle
3. 射擊：空白 → 冷卻檢查 → shootReq
4. Host 額外：子彈移動 → 碰撞偵測（坦克/牆/箱）→ HP 變化 → 道具掉落 → 勝負裁決

**建構函式：**
- `init()`: 建地面、牆、出生點、坦克 mesh、HUD、綁鍵盤
- `update()`: 插值遠端坦克、更新 HP 條、HUD、子彈動畫、爆炸特效
- `dispose()`: 清理所有 mesh/observer

### 2. 修改 `src/babylon/games/index.ts`

- `REGISTRY.tank = createTankScene`（替換 `createPlaceholderScene`）

- `TOUCH_ACTIONS['tank'] = [{ label: '🔥', key: ' ' }]`（新增射擊按鈕）

## 驗證方式
1. `pnpm lint` — 無錯誤
2. `pnpm build` — 無 TypeScript 錯誤
3. 單人模式啟動坦克遊戲 → 可移動、射擊、看到 HP 條
4. 多人模式 → 兩端坦克同步移動、子彈可命中、HP 正確減少
5. 所有 HP 歸零 → 結算畫面顯示
6. 手機觸控 → 虛擬搖桿移動 + 🔥按鈕射擊
