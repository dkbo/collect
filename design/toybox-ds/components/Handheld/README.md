# Handheld

Hero 右欄的掌機「DKBO·BOY」：黃色機身、深色螢幕放作品截圖、十字鍵、A／B 鍵。這是整套系統唯一的大型插畫物件，一頁一台。

| 部位 | 規格 |
| --- | --- |
| 機身 | 最寬 380px、Padding `space-6` `space-6` `space-8`、`pop` 底、`border-l`、圓角 `radius-xl`（右下 `radius-console` 64px）、`shadow-hard-l`、`tilt-2`（3deg） |
| 區塊間距 | `space-5` |
| 螢幕 | `inverse` 底、`border-l`、`radius-md`、Padding `space-3`；截圖 16:10、圓角 4px |
| 螢幕字幕 | `pixel-m`（20px）、`pop`，左右分置（NOW PLAYING／作品名 ▸） |
| 十字鍵 | 88 × 88，兩條 28px 寬的 `on-fill` 色條、圓角 5px |
| A／B 鍵 | 52px 圓、`action` 底、`border-m`、3px 硬陰影、`pixel-l` 字（26px）；整組 -20deg，B 往下錯開 `space-5` |
| Start／Select | 54 × 12 膠囊、`on-fill` 80% |
| 型號 | `pixel-m`、字距 0.12em、靠右 |

**互動（建議）**：A 進入目前螢幕上的作品、B 換下一張截圖；按下時位移 3px 吃掉陰影。旁邊最多放 3 張 Tag l 貼紙（`tilt-3`／`tilt-2`／`tilt-1`），不要壓住螢幕。手機版機身縮到 100% 寬，貼紙收起。
