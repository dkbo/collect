# DKBO Toybox

DKBO 個人作品站的設計系統。整個站被當成一台玩具掌機和一盒遊戲卡帶：每個可以點的東西都是一個實體物件，有墨線外框、有硬陰影，按下去會陷進去。

這份文件是給兩種讀者的規格：

- **前端工程師**：把 token 對應到 Tailwind v4 與 shadcn，照元件規格改 `index.css`、`Layout`、`Home`。見〈實作對應〉。
- **artifacts／設計 canvas**：直接載入這套系統的 `tokens.css`、`bundle.css` 與 `window.Toybox` 元件畫 mockup。

## 個性

| 是 | 不是 |
| --- | --- |
| 玩具、掌機、遊戲卡匣、貼紙、計分板 | 科技新創、SaaS 儀表板、AI 產品首頁 |
| 平面色塊、粗黑墨線、硬陰影 | 漸層、毛玻璃、模糊光暈、柔和陰影 |
| 少數幾個物件微微傾斜，像隨手貼上去 | 全部置中對齊、完美對稱 |
| 點陣字當點綴（編號、眉標、數字） | 點陣字當內文 |

## 五條原則

1. **一切都是實體物件。** 物件 = `border-m` 墨線 + 實心底 + 硬陰影。不是物件的東西（內文、區塊背景）就不要框、不要陰影。
2. **陰影就是按鍵行程。** 硬陰影的偏移量等於按下時的位移：hover 浮起、active 陷進去、陰影歸零。所有可點物件共用同一套狀態（見〈基礎〉的互動狀態）。
3. **顏色少而飽和。** 一個品牌黃 `pop`、一個行動色 `action`、三個貼紙色（`sky`、`mint`、`pink`）。色塊上的字一律 `on-fill` 深色，不用白字。
4. **黃色只代表「這裡」。** `pop` 用在 Logo、目前所在頁、主打卡帶、遊戲卡帶標籤條、掌機。不拿來當一般裝飾。
5. **每頁一個主角。** 一頁最多一台 Handheld、一張 FeatureCard、一條 Marquee、一個 CtaPanel、4 個傾斜物件。

## 禁止清單（舊站的 AI 感來源）

- 紫／靛漸層，包括漸層文字、漸層徽章、漸層 Logo。
- `blur-[120px]` 光暈、`backdrop-blur` 毛玻璃。
- 1px 灰色細框配大圓角＋柔和陰影的「標準卡片」。
- 淡色半透明底配彩色圖示的小方塊（改用 IconBox）。
- emoji 當圖示或段落標記。
- Geist／Inter／系統字當標題。

## 文案語氣

短句、動詞開頭、不加驚嘆號。按鈕：「開始玩」「開房間」「看作品」。眉標借遊戲語彙，只用英數：`SELECT GAME`、`NOW PLAYING`、`CONTINUE?`、`INSERT COIN`。中文標題要說清楚是什麼（「作品卡帶」而不是「探索無限可能」）。
